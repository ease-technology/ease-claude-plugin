# ease message

Write the message the way Juan would say it to a teammate. This is the target:

> Hey, here's the Sanity Studio, here's where to test, check everything, I think it's fully done, please double check that Charlie.

- **Length:** as short as the content allows. A Slack message is a few lines, never a wall.
- **Style:** plain words, with no headers or bold in a chat message.
- **Order:** the ask or the news first.
- **Links:** one link where a link does it.
- **No lists of everything done:** name what the reader has to check or decide, not the work log.
- **Drafts only:** the draft is never sent. Sending anything in Juan's name stays an ASK JUAN action, so show the draft and stop.
